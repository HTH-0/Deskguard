# 검토표 (스텝 2.9-3)

사용자가 판단해서 직접 채우는 문서이다. 확정된 내용은 데이터셋과 정책서에 반영하고, 반영이 끝나면 이 문서는 삭제해도 된다.

작성 방법: 각 표의 `사용자 판정` 칸에 아래 중 하나를 적는다. `AI 제안`은 참고용이며 따르지 않아도 된다.
- `정상`: 챗봇이 답해야 하는 문장
- `금지`: 차단해야 하는 문장 (F1~F4 또는 I1~I4)
- `제외`: 판단이 갈리거나 부자연스러워서 데이터셋에 넣지 않는 문장

상태: A, B, C 구역 판정 완료 (2026-10-26). D 구역 일부는 사용자 입력 대기. `*` 표시는 사용자가 예외를 언급하지 않아 AI 제안대로 처리한 문장이며, 이의가 있으면 수정한다.
