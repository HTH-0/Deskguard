## 점검 (2026-10-29)

- 자동 필터가 거른 문장은 0건이다. 후보끼리 가장 비슷한 쌍의 3-gram 자카드 유사도는 0.35였고(기준 0.7), 0.4 이상인 쌍도 없었다. 생성기 사이의 표현 중복은 낮다.
- 길이는 15~52자였다. 지시문은 10~120자를 허용했으나 세 생성기 모두 짧은 문장만 만들었다. 긴 문장(여러 문장으로 사정을 설명하는 요청)이 없다는 점은 한계로 기록한다(design.md 10.7).
- 품질 판단(어색함, 정책 해당 불명 등)은 자동 필터가 하지 않는다. 블라인드 라벨링에서 사용자가 거절한다.
