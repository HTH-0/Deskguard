# 평가용 데이터 폴더

6단계 측정(`docs/design.md` 10절)에 쓰는 데이터를 둔다. 이 폴더의 파일은 **측정 전에 동결**하며, 동결한 뒤에는 고치지 않는다. 동결 기록은 `FREEZE.md`(6-4 단계에서 만든다)에 해시로 남긴다.

## 파일

| 파일 | 내용 | 상태 |
|---|---|---|
| `koica_hr_questions_raw.csv` | 현실성 세트의 원본. 한국국제협력단(KOICA)의 인사규정 질의응답 세트에서 직원이 실제로 묻는 질문 25개(열: 구분, 문서 구분, 질문, 정답, 정답 단락). 원본 그대로이며 수정하지 않는다 | 보존(2026-10-28). 사용자 동의로 현실성 세트로 확정 |
| `paused_6_2/` | 중단한 6-2 분석 도구의 빈 껍데기와 테스트(빨강 단계). 재개 방법은 그 폴더의 README | 보존 |
| `domain_candidates.csv` 등 | 도메인 `eval` 구축(6-3)에서 만들 파일 | 아직 없음 |

- 출처: 한국국제협력단, 「인사규정 질의 응대 서비스 질의응답 세트」(2025-10-31 기준), 공공데이터포털 <https://www.data.go.kr/data/15152718/fileData.do>. 이용허락범위 제한 없음, 로그인 없이 다운로드(2026-10-28 확인). 이 파일을 쓰는 글에는 출처를 표시한다.

- 원본 SHA-256: `1d3fedc6cb9bbc2d143227faac8160dc1bf30f70efb0d48ef7175f4af1365abc` (인코딩 UTF-8 BOM).
- 규칙: (1) 생성 지시문과 후보 씨앗에 쓰지 않는다. (2) 질문, 룰, 임계값을 이 문장에 맞춰 고치지 않는다. (3) 원본은 고치지 않고, 가공한 파일은 별도 이름으로 만든다. (4) 정상 문장 25개뿐이므로 오탐율만 의미가 있다.
