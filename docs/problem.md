## 1. 처음 구상 (사용자의 말 그대로, 고치지 않는다)

> 회사와 같은 환경에서 챗지피티나 제미나이 클로드와 같은 llm 을 사용할 때 사용하는 채팅/프롬프트에서 미리 문제가 될 만한 내용들 탐지하는 사이트

## 2. 문제

- **누가:** 회사에서 업무에 외부 생성형 AI(ChatGPT, Gemini, Claude 등)를 쓰는 직원.
- **무엇이 문제인가:** 직원이 업무를 빨리 처리하려고 고객 명단, 개인정보, 비밀번호와 API 키, 내부 문서와 소스코드를 채팅에 그대로 붙여넣는다. 외부 AI에 보낸 내용은 회사 밖에 남고, 서비스에 따라 학습이나 사람의 검토에 쓰일 수 있다. 대부분은 악의가 아니라 실수이다.
- **지금 회사가 하는 일:** 외부 AI를 전면 금지하거나, 사용 지침만 배포하고 실제로는 확인하지 못한다. 금지하면 업무 효율을 잃고, 방치하면 정보가 나간다. 보낸 뒤에는 되돌릴 수 없다.
- **알려진 사례:** 2023년에 국내 대기업 직원들이 사내 소스코드와 회의 내용을 ChatGPT에 입력한 일이 알려졌고, 그 회사는 사내에서 생성형 AI 사용을 제한했다.

## 3. 만드는 것

직원과 외부 AI 사이에 두는 **검사 게이트웨이와 사내 AI 포털(사이트)**이다. 직원은 포털에서 평소처럼 채팅하고, 게이트웨이는 프롬프트가 외부 AI로 나가기 **전에** 문제가 될 만한 내용을 탐지해서 다음 중 하나로 처리한다.

| 처리 | 의미 |
|---|---|
| 허용 | 그대로 보낸다 |
| 가림 | 민감한 값을 가명으로 바꿔 보내고, 응답이 돌아오면 원래 값으로 되돌려 직원에게 보여 준다 |
| 경고 | 직원에게 무엇이 들어 있는지 알리고 확인을 받은 뒤 보낸다 |
| 차단 | 보내지 않는다 |

## 4. 성공하면 무엇이 달라지는가

- 직원은 외부 AI를 계속 업무에 쓴다. 대부분의 요청은 그대로 통과하거나, 가려진 채로 통과해서 업무가 이어진다.
- 개인정보, 자격증명, 회사 기밀은 외부 AI로 나가지 않는다.
- 게이트웨이 자체가 새 유출 경로가 되지 않는다. 검사를 위해 민감한 문장을 외부 서비스로 보내지 않고, 로그에 원문을 남기지 않는다.
- 위 세 가지를 **숫자로** 보여 준다. 네 숫자를 모두 측정한다(2026-10-29 사용자 결정).

| 기호 | 질문 | 정의 |
|---|---|---|
| X 탐지율 | 막아야 할 것을 잡았나 | 민감 정보가 들어 있는 평가 문장 중 게이트웨이가 탐지한 비율(범주별) |
| Y 오탐율 | 괜찮은 것을 방해했나 | 민감 정보가 없는 정상 업무 문장 중 가림, 경고, 차단된 비율 |
| Z 가림 후 유용성 | 가려도 일이 되나 | 가림 처리한 요청에서, 가명으로 보내고 되돌린 답(B)이 원문으로 보낸 답(A)만큼 요청을 해결한 비율. 하위 지표로 복원 성공률(가명이 빠짐없이 원래 값으로 돌아온 비율)을 함께 보고한다 |
| T 지연 | 느려지나 | 검사, 가림, 복원이 요청 하나에 더하는 시간 |

- Z 채점: 복원 성공률은 코드로 센다. 쓸모 판정은 판정 모델 Jev가 답 A와 B를 비교해 내리고, 사람이 40~50쌍을 직접 판정해 Jev와의 일치율을 측정 전에 정한 기준과 비교한 뒤에 채택한다(규칙: 외부 LLM 결과는 검증 후 채택). Jev는 게이트웨이의 일부가 아니므로 독립된 채점자이다.
- **운영 경로와 측정 경로를 구분한다.** "외부로 아무것도 보내지 않는다"는 직원의 요청이 지나가는 운영 경로의 약속이다. 측정 경로(Z의 답 A 수집, Jev 채점)는 가짜 회사의 가짜 데이터로만 하고, 운영 경로와 코드와 설정을 분리한다.

## 5. 완성 후의 결론 문장 (README 첫 줄 초안, 숫자는 측정 후에 채운다)

> 회사 직원이 ChatGPT 같은 외부 AI에 보내는 프롬프트를 나가기 전에 검사하는 게이트웨이를 만들었다. 한국어 업무 문장 N개로 측정한 결과, 개인정보와 자격증명의 X%를 탐지했고 정상 업무 요청의 Y%만 방해했으며, 가림 처리한 요청의 Z%는 답변이 그대로 쓸모 있었다. 검사는 외부로 아무것도 보내지 않고 요청당 평균 T ms를 더했다.

이 문장을 쓸 수 없게 만드는 결정(예: 측정하지 않는 범주, 외부 판정 서비스 사용)은 이 문서와 어긋나는 결정이다.

## 6. 범위

| 범위 안 | 범위 밖 (이유) |
|---|---|
| 포털에서 입력한 **텍스트** 프롬프트의 검사 | 파일 업로드, 이미지, 음성 (범위가 크다. 확장 후보) |
| 외부 AI API 한 곳과의 연결(포털 → 게이트웨이 → 외부 AI) | 직원이 ChatGPT 사이트에 직접 접속하는 경로의 차단(브라우저 확장, 네트워크 프록시. 확장 후보) |
| 응답에서 가명을 원래 값으로 되돌리기 | 응답 내용의 유해성 검사 |
| 가상의 회사 설정(코드명, 고객사, 문서 등급)과 가짜 데이터 | 실제 회사 시스템, 실제 인사·고객 데이터 연동 |
| 실수하는 직원, 그리고 가벼운 우회 시도(띄어쓰기, 한글 숫자 등 소수) | 숙련된 공격자의 의도적 유출(암호화, 스테가노그래피 등). 이 도구는 실수 방지가 목적이다 |
| 탐지 이벤트의 감사 기록(원문 없이) | 직원 감시와 징계 기능 |
| 탐지는 게이트웨이 안의 결정적 코드(형식, 검증 규칙, 회사 사전) | 로컬 모델(Qwen 등)을 쓰는 문맥 판정. 사전에 없는 기밀(D3 문맥)과 부적절한 사용(D4: 탈옥, 인젝션)이 여기에 속한다. 일주일 일정에서 가장 불확실해서 확장 후보로 미룬다(2026-10-29) |
| 외부 AI는 Gemini 하나(이미 연결됨) | 다른 외부 AI. 응답 모델은 인터페이스 하나로 바꿔 끼울 수 있게 둔다 |
