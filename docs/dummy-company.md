# 더미 회사 설정

게이트웨이를 시험하고 측정하기 위한 가상의 회사이다. 실존 회사, 인물, 제품과 관계없다. 사전 파일은 `backend/src/main/resources/company/dictionary.yml`이다.

상태: 확정 (2026-10-29, 2일차).

## 1. 회사 개요

| 항목 | 값 |
|---|---|
| 이름 | HTH 주식회사 (가상, 영문 HTH Corp.) |
| 업종 | B2B 소프트웨어(물류 관리 SaaS) |
| 규모 | 직원 약 150명. 개발, 영업, 고객지원, 인사, 재무 |
| 외부 AI 사용 | 개발자는 코드와 설정 파일, 영업과 고객지원은 고객 명단과 메일, 인사와 재무는 직원 정보와 문서를 다룬다 |

업종을 물류 SaaS로 정한 이유: 개발(자격증명, 소스코드), 영업(고객사, 연락처), 인사(개인정보)가 모두 있어서 D1~D3가 고르게 나오는 업무 문장을 만들기 쉽다.

## 2. 사전 (D3)

| 구분 | 값 |
|---|---|
| 프로젝트 코드명 (미공개) | 블루웨일, 오로라, 프로젝트 해솔, NIMBUS-7, 스톤브릿지 |
| 고객사 (계약 정보는 기밀) | 한결물산, 다온로지스, 새벽유통, 미르상사, 온빛푸드 |
| 보안 등급 표시 | 대외비, 사내한, 극비, Confidential, Internal Only |

## 3. 허용 목록

| 구분 | 값 |
|---|---|
| 대표 전화 | 02-555-0100 (휴대전화 형식이 아니라 원래 탐지되지 않지만 명시한다) |
| 대표 이메일 | contact@hth.example, support@hth.example |
| 공개 주소 | https://hth.example |

이메일 도메인은 예시 전용 최상위 도메인(`.example`)을 써서 실제 주소와 겹치지 않게 했다.

## 4. 가짜 개인 데이터의 형식 (평가 세트용, 생성은 `fake_values.py`)

| 항목 | 형식 | 검증 |
|---|---|---|
| 이름 | 한국인 성과 이름의 무작위 조합 | 없음(이름 단독은 탐지 대상이 아니다) |
| 주민등록번호 | 실제 날짜의 생년월일, 뒷자리 첫 숫자 1~4 | 탐지 규칙을 통과해야 한다 |
| 외국인등록번호 | 같은 형식, 뒷자리 첫 숫자 5~8 | 같음 |
| 휴대전화 | `010-####-####` 무작위(모두 같은 숫자 제외) | 같음 |
| 이메일 | 이름 기반 아이디 + `@mail.example`, `@hth.example`(직원) | 허용 목록과 겹치지 않음 |
| 계좌번호 | 은행명 + `###-######-##-###` 같은 형식 | 문맥 단어 포함 |
| 카드번호 | 16자리, Luhn 통과 | 같음 |
| API 키 등 | 알려진 형식의 무작위 문자열(실제로 쓸 수 없는 값) | 같음 |

생성기는 고정 난수(seed)로 같은 결과를 다시 만든다. 실제 개인정보는 쓰지 않는다.
