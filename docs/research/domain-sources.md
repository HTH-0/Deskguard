# 도메인 문구 확보를 위한 외부 자료 조사

조사일: 2026-10-28(1차 검색, 2차 직접 확인). 목적: 한국어 HR·IT 헬프데스크 도메인 문장(F1~F4 위반, 정상, 경계)을 만들 때 참고할 실제 자료를 찾는다. 사용 방식은 [design.md](../design.md) 10.4절(도메인 `eval` 구축)을 따른다.

검증 수준: **직접 확인**은 페이지나 파일을 열어 본 것이다. **검색 요약**은 웹 검색의 요약이며 원문을 열지 못했다. 직접 확인한 파일은 저장소에 복사하지 않았다(세션 임시 폴더에만 있다).

## 1. 결론

- 한국어 HR 헬프데스크의 **실제 직원 질문 로그는 공개된 대량 데이터가 없다.** 대신 **공공데이터포털에서 실제 직원 질문 25개와 IT 지원 요청 371건을 받았다.** 로그인 없이 받을 수 있고 이용허락범위는 제한 없음이다.
- 가장 가치가 큰 자료는 두 가지이다. (1) KOICA 직원 질문 25개(실제 직원의 말투), (2) ACCESS DENIED INC의 **시나리오 분류 틀**(본인과 타인, 권한자와 사칭, 정보 유형). 둘 다 문장을 그대로 쓰기보다 **구성 틀과 문체 기준**으로 쓴다.
- 한국어 공격 문장 자료(RICoTA, KorSET)는 도메인과 거리가 멀거나 접근 승인과 비상업 조건이 붙는다.
- 어떤 외부 문장도 **평가 세트에 그대로 넣지 않는다.** 씨앗으로 쓴 문장은 평가 세트에서 뺀다.

## 3. 검색 요약만 있는 자료 (원문 미확인)

| 자료 | 내용 | 활용 |
|---|---|---|
| Tensor Trust | 게임으로 모은 프롬프트 인젝션 공격 56만 건 이상(ICLR 2024 초록 기준). 영어. 데이터 위치는 논문의 안내 주소 | **게임 방식의 공격 문장 수집의 선례.** 모의 레드팀 설계의 근거 |
| Pluralistic Behavior Suite | 정책 위반 프롬프트와 대조 프롬프트를 LLM으로 만드는 방법 | 후보 생성(A-3)의 방법론 근거 |
| DynaGuard와 DynaBench | 사용자 정의 정책 가드레일과 4만 건의 다중 턴 대화 벤치마크 | 구성 방식 참고 |
| ConfAIde, PrivacyLens, ToxicChat, JailbreakBench | 프라이버시와 탈옥 평가, 실제 사용자 요청. 영어 | 우선순위 낮음 |

## 4. 활용 제안

| 자료 | 제안 | 조건과 주의 |
|---|---|---|
| KOICA 25개 | **현실성 세트(정상 문장)로 확정**(사용자 동의, 2026-10-28). 원본을 `docs/eval/`에 보존했다. 생성 지시문과 씨앗에는 쓰지 않는다. 실제 직원의 말투이므로 따로 동결해 두고 측정한다 | 25개는 규모가 작다. 해외 파견 주제는 제외 후보. 출처를 표시한다. 이 세션에서 문장을 읽었으므로 질문과 룰을 이 문장에 맞추지 않는다 |
| ACCESS DENIED INC | **도메인 `eval`의 층화 틀**로 차용: 관점(본인, 타인) × 권한(권한 있음, 없음, 사칭) × 정보 유형(급여, 평가, 연락처, 근태) | 틀만 차용하고 문장은 쓰지 않는다. 인용 표시 |
| 서울교통공사 | 구어체와 오타의 문체 다양성, 그리고 **"담당 부서 전화번호" 문의 표현은 알려진 오탐 약점(부서 대표 연락처에 F1이 반응)의 실제 사례**라서 경계 정상 후보의 표현 참고 | 도메인이 달라 HR 맥락으로 다시 써야 한다. 중복과 감정 편향 주의 |
| 경남개발공사 | IT 요청의 어휘와 주제 목록 | **직원 이름을 포함하므로 저장소에 복사하지 않는다.** 이름은 쓰지 않는다 |
| KorSET, CAGE | 승인을 받으면 F1, F4 위반 문장의 표현 변형 씨앗 | 비상업과 접근 승인 조건. 제한 유형 범주는 쓰지 않는다 |
| RICoTA | 사용하지 않는다 | 도메인 불일치, 조건 불명 |

## 5. 하지 못한 일과 이유

| 못 한 일 | 이유 | 해결 방법 |
|---|---|---|
| KorSET 전체 내용 확인 | 접근 승인제이고 로그인과 약관 동의가 필요하다. 저에게는 계정이 없다 | 사용자가 신청(학술과 안전성 연구 목적) |
| AI Hub 데이터 확인 | 검색으로 데이터 이름과 이용 조건을 확인하지 못했고 신청에 계정이 필요할 가능성이 높다 | 사용자가 aihub.or.kr에서 "민원", "상담", "FAQ"로 검색 |
| RICoTA와 CAGE의 라이선스 확정 | 저장소에 라이선스 파일이 없다. 저자에게 확인해야 한다 | 사용자가 저자에게 문의하거나 사용하지 않기 |
| 한국어 HR 실제 로그 | 공개된 대량 데이터를 찾지 못했다(없다고 단정할 수는 없다) | 모의 레드팀으로 사람이 직접 작성 |
| 사람 모집, 다른 LLM으로 후보 생성 | 사람을 모집할 수 없고, 외부 서비스에 접속과 계정이 없다 | 사용자의 지인과 사용자의 LLM 계정 |
| Tensor Trust 등 영어 자료 원문 | 우선순위가 낮아 이번에는 열지 않았다 | 필요하면 추가 조사 |

## 6. 주의

- 내려받은 파일은 집 컴퓨터에서 작업한 세션(2026-10-28)의 임시 폴더(`/tmp/...scratchpad/research_data/`)에만 있었고 **저장소에 없다.** 세션이 끝나면 사라진다. 필요하면 공공데이터포털에서 다시 받을 수 있다(로그인 불필요).
- 공공데이터포털 페이지의 표기는 틀릴 수 있다(서울교통공사 건수 불일치 확인).
- 공개 자료의 문장은 제한 유형(폭력, 혐오, 불법 행위 등)을 포함할 수 있다. 이런 문장은 외부 서비스로 보내지 않는다.
- 외부 저장소 3개(`ricota`, `cage-paper`, `accessdeniedinc`)는 읽기 전용으로 받았고 이 저장소에 복사하지 않았다.

## 7. 보류 메모: KorSET (사용자 결정 2026-10-28, 지금은 신청하지 않는다)

- 자료: Hugging Face `datumo/KorSET`. CAGE 논문의 한국어 레드팀 벤치마크이다. 행 수 1천~1만 구간, 라이선스 cc-by-nc-4.0(비상업), **접근 승인제**(수동 검토, 학술과 안전성 연구 목적).
- 쓰려면: Hugging Face 계정으로 로그인한 뒤 데이터 페이지(<https://huggingface.co/datasets/datumo/KorSET>)에서 약관에 동의하고 접근을 요청한다. 승인 기간은 알 수 없다.
- 쓸 수 있는 곳: 6-3의 후보 작성에서 F1(타인 개인정보)과 F4(보안 구성과 기밀) 위반 문장의 **표현 변형 씨앗**. 해당 범주는 `G. 개인 민감 정보 요청`과 `H. 조직/정부의 기밀 정보 요청`이다. 제한 유형 범주(불법, 폭력, 혐오 등)는 쓰지 않는다.
- 조건: 비상업 조건을 지킨다. 씨앗으로 쓴 문장은 평가 세트에서 뺀다. 저장소를 공개할 때(R12) 다시 점검한다.
- 재개 조건: 6-3에서 생성기 후보만으로 F1과 F4의 표현이 다양하지 않다고 판단될 때.
- 대안: 같은 저자의 샘플(`selectstar-ai/cage-paper`의 `data/sample_data.csv`, 2,293행)은 공개 저장소에 있으나 LICENSE가 없어 저자 문의가 필요하다.

## 8. 다른 컴퓨터에서 자료를 다시 받는 방법

직접 확인한 파일은 저장소에 복사하지 않았다(KOICA 25개 원본만 `docs/eval/`에 보존). 필요하면 공공데이터포털에서 **로그인 없이** 다시 받는다. 페이지의 다운로드 버튼을 쓰면 되고, 주소가 바뀌었을 때 대비해 상세 페이지를 함께 적는다.

| 서울교통공사 합성 챗봇(153,014행) | <https://www.data.go.kr/data/15152198/fileData.do> | `https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId=FILE_000000003523673&fileDetailSn=1&insertDataPrcus=N` | CP949 |
| 경남개발공사 PC헬프데스크(371행) | <https://www.data.go.kr/data/15138353/fileData.do> | `https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId=FILE_000000007656666&fileDetailSn=1&insertDataPrcus=N` | UTF-8 BOM |

- 경남개발공사 파일에는 직원 이름이 들어 있으므로 저장소에 넣지 않는다.
- 외부 저장소(`boychaboy/ricota`, `selectstar-ai/cage-paper`, `DrenFazlija/AccessDeniedInc`)는 `git clone --depth 1`로 다시 받을 수 있다. 클라우드 세션에서는 공개 저장소의 읽기만 가능했다.
