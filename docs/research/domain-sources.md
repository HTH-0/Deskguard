# 도메인 문구 확보를 위한 외부 자료 조사

조사일: 2026-10-28. 목적: 한국어 HR·IT 헬프데스크 도메인 문장(F1~F4 위반, 정상, 경계)을 만들 때 참고할 실제 자료를 찾는다. 사용 방식은 [design.md](../design.md) 10.4절(도메인 `eval` 구축)을 따른다.

검증 수준: **직접 확인**은 저장소를 받아 내용을 열어 본 것이다. **검색 요약**은 웹 검색이 돌려준 요약이며 원문을 열지 못했다(2차 정보). **미확인**은 위치나 조건을 확인하지 못한 것이다.

## 1. 결론

- 한국어 HR 헬프데스크의 **실제 질문 로그를 담은 공개 데이터는 찾지 못했다**(없다고 단정할 수는 없다).
- 대신 **공공데이터포털에 실제 기관의 직원용 FAQ와 IT 지원 요청 이력**이 있어서 정상 질문의 현실성을 높이는 데 쓸 수 있다. 다만 이용허락범위, 건수, 항목을 열어 보지 못했다.
- 한국어 레드팀 자료(RICoTA, KorSET)는 직접 확인했으나 **도메인(HR)과 거리가 멀고 라이선스를 확인하지 못했다**. 문장을 그대로 쓰지 않고 표현 변형의 참고로만 쓰는 것이 안전하다.
- 어떤 자료의 문장도 평가 세트에 **그대로 넣지 않는다**. 공개 데이터는 판정 모델이나 생성기의 학습 데이터와 겹칠 수 있고, 라이선스가 불명확하며, 평가 세트의 독립성을 해친다. 참고 자료는 후보 작성의 씨앗으로만 쓰고, 씨앗으로 쓴 문장은 평가 세트에서 뺀다.

## 2. 직접 확인한 자료

| 자료 | 확인한 내용 | 도메인 적합도 | 라이선스 | 활용 제안 |
|---|---|---|---|---|
| RICoTA (`boychaboy/ricota`) | 609개, 모두 한 커뮤니티 갤러리(이루다 챗봇)의 글에서 모은 대화이다. 대화 길이 중앙값 168자. 유형은 일상 대화 171, 기타 163, 성적 표현 84, 연인 대화 80, 혐오 59, 아이스브레이킹 52. 시험 목적이 `개인정보`인 것은 20개 | **낮음**(소셜 챗봇 대상, 업무 맥락 아님, 여러 줄 대화) | 저장소에 README와 LICENSE가 없다. 논문은 CC BY-SA 4.0이라고 하나 확인하지 못했다. 원문은 커뮤니티 글이고 출처 주소가 들어 있다 | 한국어 구어체 공격 표현의 참고 정도. 평가 세트로는 부적합 |
| CAGE 샘플 (`selectstar-ai/cage-paper`의 `data/sample_data.csv`) | 2,293행, 열은 `domain`, `category`, `seed`, `response`, `gt`. 12개 범주 중 우리 정책과 가까운 것은 `G. 개인 민감 정보 요청` 137행, `H. 조직/정부의 기밀 정보 요청` 63행, `L. 보안 위협` 75행. `seed`는 중앙값 약 33자의 한국어 한 문장 | **중간**(문장 모양이 F1, F4와 비슷하다. 그러나 일반인과 공인 대상이고 HR 맥락이 아니다) | 저장소에 LICENSE가 없고 README에 라이선스 문구가 없다. 전체 KorSET은 Hugging Face(`datumo/KorSET`)에 있으나 접속하지 못했다 | F1, F4 위반 문장의 **표현 변형 씨앗**. 나머지 범주(불법, 폭력, 혐오 등)는 제한 유형이라 사용하지 않는다 |

## 4. 하지 못한 일과 이유

| 못 한 일 | 이유 | 해결 방법 |
|---|---|---|
| 공공데이터포털, Hugging Face, arXiv, AI Hub, 법령 사이트의 페이지와 파일 열람 | 클라우드 세션의 네트워크 허용 목록 밖이라 연결이 거부된다(`www.data.go.kr`, `huggingface.co`, `arxiv.org`, `aihub.or.kr`, `www.law.go.kr`, `www.moel.go.kr` 모두 연결 실패. GitHub의 공개 저장소만 `git`으로 열린다) | 사용자가 환경 설정의 허용 도메인에 추가하거나, 사용자 컴퓨터에서 내려받아 전달 |
| 이용허락범위, 건수, 항목 확인 | 위와 같다. 검색 요약에는 나오지 않았다 | 각 데이터 상세 페이지에서 세 가지를 확인 |
| AI Hub 데이터 확인 | 검색으로 해당 데이터의 이름과 이용 조건을 확인하지 못했다. 이용 신청에 계정이 필요할 가능성이 높고 저에게는 계정이 없다 | 사용자가 aihub.or.kr에서 "민원", "상담", "FAQ"로 검색 |
| 라이선스 최종 확정 | RICoTA와 CAGE는 저장소에 라이선스 파일이 없고 저자에게 확인해야 한다 | 사용자가 저자에게 문의하거나 사용하지 않기 |
| 모의 레드팀의 사람 모집 | 사람을 모집할 수 없다 | 사용자의 지인과 스터디 |
| 다른 LLM으로 후보 생성 | 외부 서비스에 접속할 수 없고 계정이 없다 | 사용자가 지시문을 넣고 결과를 전달 |
| 논문 원문 확인 | arXiv가 차단되어 검색 요약에 의존했다 | 허용 도메인 추가 |

## 5. 주의

- 받은 외부 저장소(`/home/user/boychaboy/ricota`, `/home/user/selectstar-ai/cage-paper`)는 읽기 전용 확인용이며 **이 저장소에 복사하지 않았다**. 라이선스가 확인되기 전에는 복사하지 않는다.
- 공개 자료의 문장은 제한 유형(폭력, 혐오, 불법 행위 등)을 포함할 수 있다. 이런 문장은 외부 서비스로 보내지 않는다(handoff 6절 7번).
- 이 문서의 "검색 요약" 항목은 정확하지 않을 수 있다. 사용 전에 원문을 확인한다.
