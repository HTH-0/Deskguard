# Deskguard

> 사내 HR 헬프데스크 챗봇을 위한 LLM 입력 가드레일 게이트웨이

사내 HR 중심, IT 일부 헬프데스크 챗봇으로 들어가는 프롬프트를 실제 LLM API(Google `gemini-3.6-flash`)로 전달하기 전에, 직접 만든 백엔드 게이트웨이가 패턴 필터와 판정 모델을 거쳐 프롬프트 인젝션(지시 무시, 탈옥, 시스템 프롬프트 탈취, 권한 사칭)과 도메인 정책 위반(타인 정보 열람, 권한 밖 변경, 승인 우회, 보안 구성과 자격증명 노출)을 걸러낸다.

## 상태
현재 단계: 도메인 정책과 명세서 확정, 판정 모델(Jev) 한국어 PoC 합격(채택 승인 대기). 다음은 설계서이다. 상세 로드맵은 [`프로젝트_정리.md`](./docs/archive/프로젝트_정리.md), 주제 선정 배경은 [`AI보안_프로젝트_주제_후보.md`](./docs/archive/AI보안_프로젝트_주제_후보.md), 결정 기록은 [`DECISIONS.md`](./DECISIONS.md) 참고. 개발 원칙, 도메인 정책, 열린 위험은 [`docs/`](./docs)에 있다. 2026-10-26에 주제를 일반 인젝션 방어에서 도메인 정책을 추가한 형태로 넓혔고, 로드맵 문서(`프로젝트_정리.md`)는 변경 전 기준이라 아직 갱신하지 않았다. 다른 컴퓨터에서 이어서 작업하려면 [`docs/handoff.md`](./docs/handoff.md)를 먼저 읽는다.
